# 空調王

空調工事の見積書を作って、PDFで出すためのツールです。
ブラウザで開くだけで使えます（インストール不要・スマホ可）。

**同じURLを複数の会社で使えます。** 会社名・住所・ロゴ・社判は、開いた人ごとに
その端末のブラウザの中だけに保存されるので、お互いの情報は見えません。

## 最初にやること（1回だけ）

1. **［自社情報］タブ** — 会社名・住所・電話・振込先などを入れて「保存」
   - 50Airtec の方は右上の「50Airtecの情報を入れる」を押せば一発で入ります
2. **［自社情報］タブ の下にある「ロゴ」** — 会社のロゴを登録（任意／下記参照）
3. **［自社情報］タブ の下にある「社判」** — 角印を登録（下記参照）
4. **［単価マスタ］タブ** — 金額を実際の単価に書き換える（材料はCSVでまとめて入れられます／下記参照）

## 毎回の使い方

1. ［見積作成］タブで宛名・件名・工事場所を入力
2. 「単価表から追加」の項目をタップして明細を作る（数量はあとから直せる）
3. 必要なら「＋ 空の行」で自由な項目を追加
4. ［見積書を印刷 / PDF］→ 印刷画面で「送信先＝PDFに保存」を選ぶとPDFになります

## ロゴの入れ方

［自社情報］→ ロゴ →「ロゴの画像・データを選ぶ」でファイルを選ぶだけです。
**入れなくても大丈夫です。** 入れると、見積書の右上、会社名の上に印字されます。

対応形式：**PNG / JPEG / SVG / WebP / GIF / BMP**

- 背景が透明なPNG・SVGなら、そのまま自然に乗ります
- **社判とちがい、白い背景を抜く加工はしません。** ロゴは「見せたい形」がそのまま
  正解だからです。背景を消したい場合は透過PNGで用意してください
- SVGは600pxに描き直してから取り込むので、拡大しても粗くなりません

大きさは「ロゴの高さ（mm）」で決めます。**10〜16mm** くらいが見積書になじみます。

横に長いロゴは、幅が52mmを超えないところで自動的に収まります（用紙からはみ出さないため）。
そのぶん高さは指定より小さくなりますが、縦横の比率は崩れません。

## 社判（角印）の入れ方

**電子印鑑のデータでも、紙に押して撮った写真でも、どちらでも使えます。**

### A. 電子印鑑のデータを持っている場合

［自社情報］→ 社判 →「社判の画像・データを選ぶ」でファイルを選ぶだけです。

対応形式：**PNG / JPEG / SVG / WebP / GIF / BMP**

すでに背景が透明なデータ（透過PNG・SVG）は、**加工せずそのまま**取り込みます。
「白い背景を透明にする」のチェックが入っていても、透過データは自動で判定して素通しするので、
印影が黒くつぶれたりしません。SVGは600pxに描き直してから取り込むので、拡大しても粗くなりません。

PDFやWord・Excelに貼ってある印影は直接読めません。PNGで書き出してからお使いください。

### B. 紙に押した社判を使う場合

1. 社判を**白い紙に押す**
2. スマホで**真上から・明るいところで**撮る（斜めだと歪みます）
3. 同じく「社判の画像・データを選ぶ」で選ぶ

「白い背景を透明にする」にチェックが入っていれば、紙の白い部分が自動で消えて、
印影だけが見積書に乗ります。少しグレーがかった紙でも抜けるようにしてあります。

### 共通

大きさは「社判の大きさ（mm）」で調整します。実物の角印はだいたい 18〜24mm です。

社判は代表者名の右に印字されます。登録していない場合は「㊞」の文字だけが入ります。

## 機器の本体価格を入れる（機器を選ぶ）

エアコン本体は、材料とちがって「シリーズ・室内機タイプ・馬力・電源…」の
組み合わせで形名が決まります。そこで、**選んでいくだけで機種が決まる**しくみを用意しました。

### 準備（1回だけ）

［単価マスタ］タブ →「**機種データを選ぶ**」で
`デスクトップ\三菱スリム_機種データ.json` を読み込みます。

### 使い方

［見積作成］タブの「**機器を選ぶ**」で、上から順に押していくだけです。

```
1. シリーズ    … スリムZR / スリムER / ズバ暖スリムH / ズバ暖スリムDH
2. 室内機タイプ … 4方向天井カセット / 天吊 / 壁掛 / 床置 …（10種）
3. 馬力        … 1 / 1.5 / 1.8 / 2 / 2.3 / 2.5 / 3 / 4 / 5 / 6 / 8 / 10
4. 台数        … シングル / 同時ツイン / 同時トリプル / 同時フォー
5. 電源        … 三相200V / 単相200V
6. リモコン    … ワイヤード / ワイヤレス / リモコン内蔵
```

**その時点で実際に存在する選択肢しか出ません。** 例えば「厨房用」を選ぶと
馬力は 3・5・6・10 だけになります。行き止まりになりません。

**選択肢が1つしかない段階は、自動で決まって次に進みます。**

最後に候補が**安い順**で出ます。同じ条件でも、ムーブアイ・ぐるスマ・清潔パネル・
無線通信キットの有無で価格が変わるので、装備の違いを見て選んでください。

```
PLZ-ZRMP80HF6    ¥1,536,000  人感ムーブアイ・ワイド
PLZ-ZRMP80HBF6   ¥1,575,000  人感ムーブアイ・無線通信キット・ワイド
PLZ-ZRMP80HFG6   ¥1,616,000  人感ムーブアイ・ぐるスマ・ワイド
```

押すと明細に入ります。仕様欄には形名・能力・台数・電源・リモコン・装備がまとめて入り、
🔍 ボタンから製品ページも開けます。

### 注意

- 価格は**メーカー標準価格（税別）**です。**配管・据付工事費は含みません**
- 途中で条件を変えたいときは、その手順の「変更」を押します（それより下はやり直しになります）
- 「最初から」で全部リセットできます

### 対応メーカー

いまは**三菱電機 Mr.SLIM のみ**です（1,097機種）。
ダイキンは公式サイトに価格が公開されていないため、いまは入っていません。

## 材料の単価を入れる

因幡電工などメーカーの価格表は、**このツールには入っていません**。
定価は公開されていないので、こちらで勝手に金額を書くことはしていません。
実際に使う品目を、下の3つのどれかで入れてください。

### 方法1：Excelから貼り付ける（一番早い）

Excelやメモ帳で品番・品名・単位・定価を並べておき、**範囲を選んでコピー** →
［単価マスタ］タブの「Excelやメモ帳からそのまま貼り付ける」欄に貼って「取り込む」。
ファイルに保存する必要はありません。

```
LD-70	スリムダクト LD ダクト	本	1200
HPC-2320	ペアコイル 2分3分	巻	18000
```

列の数で並びを判断します（2列＝品名と定価／3列＝品名・単位・定価／
4列＝品番・品名・単位・定価／5列以上＝品番・品名・規格・単位・定価）。
**取り込む前に「どう読み取ったか」を確認画面で見せる**ので、
ズレていたらキャンセルできます。

### 方法2：画面で1つずつ打ち込む

［単価マスタ］→ 分類を開く →「＋ 項目を追加」。空の行ができて品番欄にカーソルが入るので、
**品番 → Tab → 品名 → Tab → … → 単価 → Enter** で次の行が出ます。
30〜50品目ならこれが確実です。

### 方法3：見積を作りながら登録する

見積作成中に「この材料、まだ単価表に入れてなかった」となったら、
「＋ 空の行」で入力してから、その行の右にある **`＋表`** ボタンを押してください。
いま選んでいる分類に登録され、次からは選ぶだけになります。

品番は仕様欄の先頭に書いておけば（例：`FP-100　100A用`）、自動で品番として切り出します。
同じ項目が既にある場合は重複せず、単価だけ更新するか聞かれます。

### 方法4：CSVファイルで取り込む

将来メーカーや商社から価格データをもらえたとき用です。

1. ［単価マスタ］タブ →「テンプレートCSVを取得」で見本をダウンロード
2. Excelで埋めて **CSV形式で保存**
3. 「CSVを選ぶ」で読み込む

### CSVの書き方

見出し行は `カテゴリ, 品番, 品名, 規格, 単位, 定価, URL`。
**並び順は自由**で、要らない列はまるごと無くてもOKです。

```
カテゴリ,品番,品名,規格,単位,定価,URL
材料（因幡電工）,LD-70,スリムダクト LD ダクト,ダクト70,本,1200,https://www.inaba-denko.com/ja/product/detail/1540000
材料（因幡電工）,HPC-2320,ペアコイル 2分3分,20m,巻,18000,
```

- 「型番」「商品名」「希望小売価格」など、**よくある別の言い方でも認識**します
- 見出し行が無い場合は `品番, 品名, 規格, 単位, 定価` の順とみなします
- `カテゴリ` 列が無い行は、画面で選んだカテゴリに入ります
- `¥1,200` `850円` `１２００`（全角）も、そのまま数字として読めます
- **Excelから出したShift_JISのCSVもそのまま読めます**（文字化けしません）
- 「取り込む前にカテゴリの中身を空にする」にチェックを入れると、価格改定のときに丸ごと入れ替えできます

### 製品ページへのリンク（URL列）

`URL` 列を入れておくと、見積の明細行と単価マスタの行に **🔍 ボタン**が出ます。
押すとメーカーの製品ページが新しいタブで開くので、見積を作りながら
「この材料どんなやつだっけ」を確かめられます。

安全のため **`https://` と `http://` で始まるものだけ**を受け付けます。
それ以外（`javascript:` など）が書かれていても無視するので、
知らないCSVを取り込んでも変なものが動くことはありません。

URLが無い項目にはボタンが出ないだけで、ほかの動きは変わりません。
見積書の印刷にもボタンは出ません。

### 使うとき

見積作成画面の検索欄に **品番を打てば出てきます**（例：`LD-70`）。
選ぶと、単価には**定価がそのまま**入ります。値引きするときはその場で単価を直すか、
下の「値引き」欄でまとめて引いてください。

品番は見積書の品名の下に小さく印字されます。

### ★よく使う

一度でも選んだ項目は、選んだ回数を覚えていて、
分類の一番左に出る **「★ よく使う」** にまとまります（多い順に最大40件）。

数千件の材料を入れても、実際に使うのは数十件のはずなので、
2〜3回見積を作れば、よく使う材料はここだけで済むようになります。

※3,000件入れても動作を確認済みです（保存サイズ約236KB、画面表示16ms）。

## データの置き場所について

自社情報・ロゴ・社判・単価・作った見積は、すべて**この端末のブラウザの中（localStorage）
にだけ**保存されます。サーバーにもGitHubにも送られません。

そのため注意点が2つあります。

- **端末をまたいで自動では共有されません。** スマホとパソコンの両方で使うなら、
  ［単価マスタ］→［バックアップを書き出す］でJSONファイルを作り、
  もう一方の端末で［読み込む］してください（自社情報・ロゴ・社判・機種データも、このファイル1つに入っています）。
  見積データは［保存済み］タブ側で同じ手順です。
- **ブラウザの「閲覧データを削除」をすると消えます。** ときどきバックアップを
  書き出してクラウドなどに置いておくと安心です。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目（画面用 ＋ A4印刷用） |
| `app.js` | 計算・保存・ロゴと社判の加工・印刷の処理 |
| `pricebook.js` | 初期単価マスタ（**仮の目安金額**。実単価はツール上で編集する） |

`pricebook.js` の金額はGitHubで公開されます。本当の単価をここに書かないでください。

## 検索避け

`/tools/` は `robots.txt` で除外し、`index.html` にも `noindex` を入れてあるので
検索結果には出ません。ただしURLを知っていれば誰でも開けます
（初期状態＝何も登録されていない状態で開きます）。
