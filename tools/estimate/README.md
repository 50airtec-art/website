# 空調王

空調工事の見積書を作って、PDFで出すためのツールです。
ブラウザで開くだけで使えます（インストール不要・スマホ可）。

**同じURLを複数の会社で使えます。** 会社名・住所・ロゴ・社判は、開いた人ごとに
その端末のブラウザの中だけに保存されるので、お互いの情報は見えません。

## 最初にやること（1回だけ）

1. **［自社情報］タブ** — 会社名・住所・電話・振込先などを入れて「保存」
   - 50Airtec の方は右上の「50Airtecの情報を入れる」を押せば一発で入ります
2. **［自社情報］タブ の下にある「ロゴ」** — 会社のロゴを登録（任意／下記参照）
3. **［自社情報］タブ の下にある「社判」** — 角印を登録（下記参照）
4. **［単価マスタ］タブ** — 金額を実際の単価に書き換える（材料はCSVでまとめて入れられます／下記参照）

## 毎回の使い方

1. ［見積作成］タブで宛名・件名・工事場所を入力
2. 「単価表から追加」の項目をタップして明細を作る（数量はあとから直せる）
3. 必要なら「＋ 空の行」で自由な項目を追加
4. ［見積書を印刷 / PDF］→ 印刷画面で「送信先＝PDFに保存」を選ぶとPDFになります

## ロゴの入れ方

［自社情報］→ ロゴ →「ロゴの画像・データを選ぶ」でファイルを選ぶだけです。
**入れなくても大丈夫です。** 入れると、見積書の右上、会社名の上に印字されます。

対応形式：**PNG / JPEG / SVG / WebP / GIF / BMP**

- 背景が透明なPNG・SVGなら、そのまま自然に乗ります
- **社判とちがい、白い背景を抜く加工はしません。** ロゴは「見せたい形」がそのまま
  正解だからです。背景を消したい場合は透過PNGで用意してください
- SVGは600pxに描き直してから取り込むので、拡大しても粗くなりません

大きさは「ロゴの高さ（mm）」で決めます。**10〜16mm** くらいが見積書になじみます。

横に長いロゴは、幅が52mmを超えないところで自動的に収まります（用紙からはみ出さないため）。
そのぶん高さは指定より小さくなりますが、縦横の比率は崩れません。

## 社判（角印）の入れ方

**電子印鑑のデータでも、紙に押して撮った写真でも、どちらでも使えます。**

### A. 電子印鑑のデータを持っている場合

［自社情報］→ 社判 →「社判の画像・データを選ぶ」でファイルを選ぶだけです。

対応形式：**PNG / JPEG / SVG / WebP / GIF / BMP**

すでに背景が透明なデータ（透過PNG・SVG）は、**加工せずそのまま**取り込みます。
「白い背景を透明にする」のチェックが入っていても、透過データは自動で判定して素通しするので、
印影が黒くつぶれたりしません。SVGは600pxに描き直してから取り込むので、拡大しても粗くなりません。

PDFやWord・Excelに貼ってある印影は直接読めません。PNGで書き出してからお使いください。

### B. 紙に押した社判を使う場合

1. 社判を**白い紙に押す**
2. スマホで**真上から・明るいところで**撮る（斜めだと歪みます）
3. 同じく「社判の画像・データを選ぶ」で選ぶ

「白い背景を透明にする」にチェックが入っていれば、紙の白い部分が自動で消えて、
印影だけが見積書に乗ります。少しグレーがかった紙でも抜けるようにしてあります。

### 共通

大きさは「社判の大きさ（mm）」で調整します。実物の角印はだいたい 18〜24mm です。

社判は代表者名の右に印字されます。登録していない場合は「㊞」の文字だけが入ります。

## 現場ごとに管理する

［現場］タブが入り口です。**1つの現場に、現調チェックシートと見積が何件でもぶら下がります。**

```
現場一覧
  〇〇商店 事務所エアコン更新   ¥760,000  見積3件
  △△工場 工場空調増設        ¥900,000  見積1件
      ↓ タップ
  現調チェックシート（11 / 68 項目）
  見積 No.1（当初）  No.2（変更）  No.3
  ＋ この現場で見積を作る
```

- 「＋ この現場で見積を作る」を押すと、**宛名・件名・工事場所が入った状態**で見積が始まります
- **見積を保存すると、現場が無ければ自動で作られます**（件名が現場名になります）
- 現場名・お客様名で検索できます
- 現場を削除すると、中の見積も一緒に消えます（件数を出して確認します）

**以前の見積も自動でふり分けられます。** 宛名と件名が同じ見積は1つの現場にまとまるので、
手作業での整理は要りません。

## 現地調査チェックシート

現場の中にあります。紙の「空調設備現場調査確認表」と同じ**6セクション・59項目**です。

- スマホで入力しやすいよう、**セクションごとに開いたり閉じたり**できます
- 案件名・お客様名・現場住所は、**現場の情報から自動で入ります**
- 入力するとその場で保存され、「11 / 68 項目」と進み具合が出ます
- **［印刷 / PDF］** … 記入済みの状態で印刷（チェックは ☑ で出ます）
- **［白紙で印刷］** … 何も記入していない状態。現場に持っていく用です

項目を足したり減らしたりしたいときは、`survey.js` を直せば画面と印刷の両方に反映されます。

## 請求書

現場の中の見積の行にある **［請求書］** を押すと、その見積の金額をそのまま引き継いだ
請求書ができます。支払期限を「今日から何日後か」で聞かれるので、数字を入れるだけです。

**見積は書き換わりません。** あとから見積を直しても、出した請求書はそのまま残ります。

- 請求番号は `20260827-01` の形で自動採番（見積番号とは別の連番）
- 請求日・工事完了日・支払期限は［日付を直す］で後から変えられます
- 見積用の但し書き（※本見積は…）は引き継ぎません。振込先は自社情報から自動で入ります

### インボイス（適格請求書）に対応しています

法律で決まっている記載事項が入るようにしてあります。

| 記載事項 | どこに出るか |
|---|---|
| 発行者の名称 | 右上（自社情報の会社名） |
| **登録番号** | 右上（自社情報の「登録番号」欄） |
| 取引年月日 | 請求日／工事完了日 |
| 取引内容 | 明細 |
| **税率ごとに区分した対価の額** | 合計表の「10%対象」 |
| **税率ごとに区分した消費税額** | 合計表の「うち消費税」 |
| 交付を受ける事業者の名称 | 左上の宛名 |

空調工事は軽減税率の対象外なので、税率の区分は10%の1つだけです。

**登録番号は［自社情報］の「登録番号（インボイス）」欄に入れてください。**
空欄だと請求書に登録番号が出ず、適格請求書になりません。

## 掛率（行ごとに値引きを入れる）

明細の各行に「**掛率**」のプルダウンがあります。**定価の何%で出すか**を選ぶと、
単価がその場で計算されます。

```
標準取付工事  掛率100%  ¥16,000
              掛率 80%  ¥12,800   ← 16,000 × 0.8
              掛率 65%  ¥10,400
```

選べるのは 100 / 95 / 90 / 85 / 80 / 75 / 70 / 65 / 60 / 55 / 50 % です。

- **100%に戻せば元の定価に戻ります。** 元の値は行の中に持っているので、
  何度変えても定価を見失いません
- 100%以外の行は**プルダウンに色が付く**ので、値引きした行がひと目で分かります
- 単価の欄にマウスを乗せると「定価 ¥16,000 の 80%」と出ます
- **単価を手で打ち直すと、その金額が新しい元値になり、掛率は100%に戻ります**

**掛率は見積書には印刷されません。** お客様に見えるのは単価と金額だけです。

全体にまとめて掛けたいときは、下の「諸経費（小計の%）」や「値引き」を使ってください。
（ただし次の「諸経費（現場管理費）」の行を使うときは、「諸経費（小計の%）」は0のままに）

## 消耗品雑費と諸経費（自動で計算されます）

金額を打ち込まなくてよい項目が2つあります。明細に入れるだけで、**そのときの中身に合わせて単価が自動で決まります**。

| 項目 | どこにある | 何の合計の何% |
|---|---|---|
| **消耗品雑費** | 家庭用・業務用の両方 | **作業費**の **5%** |
| **諸経費（現場管理費）** | その他・値引き | **作業費＋消耗品雑費**の **15%** |

**家庭用の工事でも業務用と同じ**です。消耗品雑費は家庭用・業務用のどちらの分類にも置いてあるので、
そのとき開いている分類から入れられます。**どちらから入れても金額は同じ**なので、
家庭用と業務用がまざった現場でも、消耗品雑費は1行だけで大丈夫です。

```
天井カセット4方向 取付 3馬力   ¥120,000
電源工事（三相200V）           ¥45,000
                               ────────
作業費の合計                   ¥165,000
消耗品雑費（5%）               ¥8,250     ← 165,000 × 5%
                               ────────
作業費＋消耗品雑費             ¥173,250
諸経費（15%）                  ¥25,988    ← 173,250 × 15%
```

### 「作業費」に数えるもの

**家庭用・業務用・移設の3つの分類から入れた行だけ**です。
テープ・パテ・ドレンホースといった消耗品も、現場を回す手間も、工事の量に比例して増えるものなので、
**機器本体・材料（因幡などCSVで取り込んだもの）・値引きの行は数えません**。

### 使うときに知っておくこと

- 作業費の行を足したり数量や掛率を変えたりすると、**その場で両方とも計算し直されます**
- 明細の**どこに置いても金額は変わりません**。並び順は好きにして大丈夫です
- この2行の単価は手では書き換えられません（掛率も使いません）
- 同じ項目を**2回入れようとすると止めます**（二重に乗るのを防ぐため）
- 単価の欄にマウスを乗せると「作業費の合計 ¥165,000 の 5%」のように、もとにした金額が出ます
- 明細の下の合計欄に「**作業費（画面のみ）**」が出るので、いくらをもとに計算したか確認できます
  （この行は**画面だけ**で、見積書には印刷されません）
- 見積書には **「消耗品雑費　一式　¥8,250」「諸経費　一式　¥25,988」** としか印刷されません。
  5%・15%という計算のしかたはお客様には見えません

### ⚠ 見積画面の「諸経費（小計の%）」は0のままに

見積画面の下のほうにも「諸経費（小計の%）」の欄があります。
**この諸経費の行を使うときは、そちらは0のままにしてください。**二重に諸経費が乗ってしまいます。

### 割合（5%・15%）を変えたいとき

［単価マスタ］でその項目の行を出すと、単価の欄が **「5 % 作業費」「15 % 作業費＋雑費」** に
なっています。この数字を書き換えれば、次に入れる見積から新しい割合になります。

### 「工」ボタンで、数える／数えないを決められる

明細の各行の右側に「**工**」のボタンがあります。**青く光っている行が、いま作業費に数えられている行**です。
押すたびに切り替わります。

- 「＋ 空行を追加」で**手で打った行**は、どの分類のものか分からないので最初は数えません。
  作業費に入れたいときは「工」を押して青くしてください
- 逆に、単価マスタから入れた工事でも「これは今回は数えたくない」ときは「工」を押して消せます
- 押すとすぐ消耗品雑費と諸経費が計算し直されます

### この機能より前に作った見積を開いたとき

古い見積の行は「どの分類から入れたか」を持っていません。そのままだと作業費が0円になってしまうので、
**開いたときに品名を単価マスタと突き合わせて、自動で印を付け直します**。
単価マスタに無い品名（手で打った行）だけは印が付かないので、上の「工」ボタンで足してください。

## 機器の本体価格を入れる（機器を選ぶ）

エアコン本体は、材料とちがって「シリーズ・室内機タイプ・馬力・電源…」の
組み合わせで形名が決まります。そこで、**選んでいくだけで機種が決まる**しくみを用意しました。

### 準備（1回だけ）

［単価マスタ］タブ →「**機種データを選ぶ**」で
`三菱スリム_機種データ.json` を読み込みます。

### 使い方

［見積作成］タブの「**機器を選ぶ**」で、上から順に押していくだけです。

```
1. シリーズ    … スリムZR / スリムER / ズバ暖スリムH / ズバ暖スリムDH
2. 室内機タイプ … 4方向天井カセット / 天吊 / 壁掛 / 床置 …（10種）
3. 馬力        … 1 / 1.5 / 1.8 / 2 / 2.3 / 2.5 / 3 / 4 / 5 / 6 / 8 / 10
4. 台数        … シングル / 同時ツイン / 同時トリプル / 同時フォー
5. 電源        … 三相200V / 単相200V
6. リモコン    … ワイヤード / ワイヤレス / リモコン内蔵
```

**その時点で実際に存在する選択肢しか出ません。** 例えば「厨房用」を選ぶと
馬力は 3・5・6・10 だけになります。行き止まりになりません。

**選択肢が1つしかない段階は、自動で決まって次に進みます。**

最後に候補が**安い順**で出ます。同じ条件でも、ムーブアイ・ぐるスマ・清潔パネル・
無線通信キットの有無で価格が変わるので、装備の違いを見て選んでください。

```
PLZ-ZRMP80HF6    ¥1,536,000  人感ムーブアイ・ワイド
PLZ-ZRMP80HBF6   ¥1,575,000  人感ムーブアイ・無線通信キット・ワイド
PLZ-ZRMP80HFG6   ¥1,616,000  人感ムーブアイ・ぐるスマ・ワイド
```

押すと明細に入ります。仕様欄には形名・能力・台数・電源・リモコン・装備がまとめて入り、
🔍 ボタンから製品ページも開けます。

### 注意

- 価格は**メーカー標準価格（税別）**です。**配管・据付工事費は含みません**
- 途中で条件を変えたいときは、その手順の「変更」を押します（それより下はやり直しになります）
- 「最初から」で全部リセットできます

### 対応メーカー

いまは**三菱電機 Mr.SLIM のみ**です（1,097機種）。
ダイキンは公式サイトに価格が公開されていないため、いまは入っていません。

## 材料の単価を入れる

因幡電工などメーカーの価格表は、**このツールには入っていません**。
定価は公開されていないので、こちらで勝手に金額を書くことはしていません。
実際に使う品目を、下の3つのどれかで入れてください。

### 方法1：Excelから貼り付ける（一番早い）

Excelやメモ帳で品番・品名・単位・定価を並べておき、**範囲を選んでコピー** →
［単価マスタ］タブの「Excelやメモ帳からそのまま貼り付ける」欄に貼って「取り込む」。
ファイルに保存する必要はありません。

```
LD-70	スリムダクト LD ダクト	本	1200
HPC-2320	ペアコイル 2分3分	巻	18000
```

列の数で並びを判断します（2列＝品名と定価／3列＝品名・単位・定価／
4列＝品番・品名・単位・定価／5列以上＝品番・品名・規格・単位・定価）。
**取り込む前に「どう読み取ったか」を確認画面で見せる**ので、
ズレていたらキャンセルできます。

### 方法2：画面で1つずつ打ち込む

［単価マスタ］→ 分類を開く →「＋ 項目を追加」。空の行ができて品番欄にカーソルが入るので、
**品番 → Tab → 品名 → Tab → … → 単価 → Enter** で次の行が出ます。
30〜50品目ならこれが確実です。

### 方法3：見積を作りながら登録する

見積作成中に「この材料、まだ単価表に入れてなかった」となったら、
「＋ 空の行」で入力してから、その行の右にある **`＋表`** ボタンを押してください。
いま選んでいる分類に登録され、次からは選ぶだけになります。

品番は仕様欄の先頭に書いておけば（例：`FP-100　100A用`）、自動で品番として切り出します。
同じ項目が既にある場合は重複せず、単価だけ更新するか聞かれます。

### 方法4：CSVファイルで取り込む

将来メーカーや商社から価格データをもらえたとき用です。

1. ［単価マスタ］タブ →「テンプレートCSVを取得」で見本をダウンロード
2. Excelで埋めて **CSV形式で保存**
3. 「CSVを選ぶ」で読み込む

### CSVの書き方

見出し行は `カテゴリ, 品番, 品名, 規格, 単位, 定価, URL, 色`。
**並び順は自由**で、要らない列はまるごと無くてもOKです。

```
カテゴリ,品番,品名,規格,単位,定価,URL
材料,LD-70,スリムダクト LD ダクト,ダクト70,本,1200,https://www.inaba-denko.com/ja/product/detail/1540000
材料,HPC-2320,ペアコイル 2分3分,20m,巻,18000,
```

- 「型番」「商品名」「希望小売価格」など、**よくある別の言い方でも認識**します
- 見出し行が無い場合は `品番, 品名, 規格, 単位, 定価` の順とみなします
- `カテゴリ` 列が無い行は、画面で選んだカテゴリに入ります
- `¥1,200` `850円` `１２００`（全角）も、そのまま数字として読めます
- **Excelから出したShift_JISのCSVもそのまま読めます**（文字化けしません）
- 「取り込む前にカテゴリの中身を空にする」にチェックを入れると、価格改定のときに丸ごと入れ替えできます

### 製品ページへのリンク（URL列）

`URL` 列を入れておくと、見積の明細行と単価マスタの行に **🔍 ボタン**が出ます。
押すとメーカーの製品ページが新しいタブで開くので、見積を作りながら
「この材料どんなやつだっけ」を確かめられます。

安全のため **`https://` と `http://` で始まるものだけ**を受け付けます。
それ以外（`javascript:` など）が書かれていても無視するので、
知らないCSVを取り込んでも変なものが動くことはありません。

URLが無い項目にはボタンが出ないだけで、ほかの動きは変わりません。
見積書の印刷にもボタンは出ません。

### 使うとき

見積作成画面の検索欄に **品番を打てば出てきます**（例：`LD-70`）。
選ぶと、単価には**定価がそのまま**入ります。値引きするときはその場で単価を直すか、
下の「値引き」欄でまとめて引いてください。

品番は見積書の品名の下に小さく印字されます。

### ★よく使う

一度でも選んだ項目は、選んだ回数を覚えていて、
分類の一番左に出る **「★ よく使う」** にまとまります（多い順に最大40件）。

数千件の材料を入れても、実際に使うのは数十件のはずなので、
2〜3回見積を作れば、よく使う材料はここだけで済むようになります。

※3,000件入れても動作を確認済みです（保存サイズ約236KB、画面表示16ms）。

## 現場はスマホ、事務所はパソコン

**［自社情報］の「スマホとパソコンの連動」を入れておくと、自動でそろいます。**
設定していない場合は、下の「手で運ぶ方法」でも今までどおり使えます。

```
現場（スマホ）              事務所（パソコン）
──────────   ⇄⇄⇄   ──────────
現調シートを入力            見積を作る
現場を追加                  請求書を出す
```

| データ | 連動あり | 連動なし（手で運ぶ） |
|---|---|---|
| 現場・現調シート・見積・請求書 | 自動でそろう | 文字でコピーして送る（下記） |
| 単価・機種データ・自社情報・ロゴ・社判 | 自動でそろう | 最初に1回スマホに入れる |

### かんたんバックアップ（パソコン）

［自社情報］の「端末を移すとき」の中にあります。

**「保存先を決める」を1回押して、OneDrive の中にファイルを作ってください。**
次からは **「いますぐ保存」を押すだけ**で、そのファイルに上書きされます。
OneDrive に置けば、そのままクラウドにも残るので二重に安心です。

- 保存先を決めてあり、前回から1日以上たっていれば、**開いたときに自動で保存**します
- **14日バックアップしていないと、画面の上に黄色い帯**が出て知らせます
- 保存先を決めていない場合や、スマホの場合は、いつものダウンロード保存になります

この機能はパソコンの Chrome / Edge で使えます。
スマホでは「全部まとめて書き出す」でファイルを作ってください。

### 最初にスマホへ入れる（1回だけ）

パソコンの ［自社情報］→「**全部まとめて書き出す**」で1ファイルを作り、
スマホに送って ［自社情報］→「**まとめて読み込む**」。

自社情報・ロゴ・社判・単価・機種データ・現場・現調シート・見積・請求書が**すべて入っています**。
以前のように2つのファイルを運ぶ必要はありません。

### 現調シートを現場から事務所へ（毎回）

1. 現場でスマホに入力（現場もスマホで作ってOK）
2. 現調シートの **［コピー］** を押す
3. LINEなどで自分宛に貼り付けて送る
4. パソコンで受け取った文字をコピー
5. ［現場］タブの **「現調シートを貼り付け」** → 文字を貼って OK

**パソコン側に現場が無ければ、自動で作られます。** お客様名・住所・連絡先も、
シートの基本情報から一緒に入ります。同じ名前の現場が既にあれば、そこに上書きされます
（現場が二重にできることはありません）。

特定の現場を狙って入れ直したいときは、その現場を開いて中の ［貼り付け］ を使ってください。

送られる文字は**読んで分かる形**なので、そのままLINEで現場の様子を伝えるのにも使えます。

```
【空調王】現調シート
現場: 事務所エアコン更新

■ 1. 建物・使用条件
用途: 店舗
対象面積・天井高: 120㎡ / 2.7m
構造: S造
```

**入力した内容は1文字も欠けずに戻ります**（複数行の所見の改行も保たれます）。

## スマホとパソコンの連動（自動）

［自社情報］タブの「**スマホとパソコンの連動**」で設定します。

### つなぎ方（1回だけ）

1. **パソコン**で「**この端末で連動を始める**」を押す
   → 20文字の「**あいことば**」が出ます（例 `FPHGD-F8M7P-33TP8-3E3TH`）
2. **スマホ**で同じページを開き、「**あいことばを入れる**」を押して入力
3. 「連動しました」と出れば完了。以降は自動でそろいます

- あいことばは**紙にも控えておいてください**。これを無くすと、預けたデータは誰にも開けません
- 3台目（別のパソコンなど）も、同じあいことばを入れれば仲間に入れます

### どう動くか

- 保存するたびに送り、**開いたとき・画面に戻ったとき・45秒ごと**に受け取ります
- 相手の変更が届くと、画面を作り直します（入力中は「画面を新しくする」の帯が出るだけ）
- 圏外のときは何もしません。つながったらまとめて送ります
- 現場・見積・請求書は**1件ずつ突き合わせ**ます。両方で同じ現場を直したときは、**あとから直したほうが残ります**
- 単価マスタ・機種データは**まるごと1つ**。あとから直したほうが勝ちです
- あとから入る端末の単価マスタは、**先に連動していたほうの内容に置き換わります**

### 安全のしくみ

| | |
|---|---|
| 中身 | **端末の中で暗号（AES-256）に変えてから**預ける。クラウド側には意味の分からない文字列しか残らない |
| カギ | あいことば。**クラウドには送らない**ので、Google側でも中身は開けない |
| 置き場所 | あいことばから作った**当てられない64桁**の名前 |
| ルール | ログインした端末だけ・決まった形の名前だけ（`firestore.rules`） |

**それでも「絶対」ではありません。**「全部まとめて書き出す」バックアップは、今までどおり続けてください。

### クラウド側の準備（開発者向け・1回だけ）

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作る（無料のSparkプランでよい）
2. **Firestore Database** を作る（ロケーションは `asia-northeast1`）
3. **Authentication → ログイン方法 → 匿名** を有効にする
4. **Firestore → ルール** に `firestore.rules` の中身を貼って公開
5. **プロジェクトの設定 → マイアプリ（ウェブ）** を追加し、出てきた `apiKey` と `projectId` を
   `firebase-config.js` に書き写す

`apiKey` は秘密のカギではなく「どのプロジェクトか」を示す住所なので、公開されていて問題ありません
（守っているのは、上の表の暗号・64桁の名前・ルールの3つです）。

`firebase-config.js` が空のあいだ、連動の欄は「準備中」と表示され、ツールは今までどおり
端末の中だけで動きます。

## データの置き場所について

自社情報・ロゴ・社判・単価・作った見積は、**この端末のブラウザの中（localStorage）**に
保存されます。連動を設定していない場合は、サーバーにもGitHubにも送られません。
連動を設定した場合は、**暗号にしたもの**だけがクラウドに置かれます。

そのため注意点が2つあります。

- **連動を設定していないと、端末をまたいで自動では共有されません。** スマホとパソコンの両方で使うなら、
  ［単価マスタ］→［バックアップを書き出す］でJSONファイルを作り、
  もう一方の端末で［読み込む］してください（自社情報・ロゴ・社判・機種データも、このファイル1つに入っています）。
  見積データは［保存済み］タブ側で同じ手順です。
- **ブラウザの「閲覧データを削除」をすると消えます。** ときどきバックアップを
  書き出してクラウドなどに置いておくと安心です。

### 色分け（色列）

`色` 列を入れておくと、**単価表から選ぶときの文字色**が変わります。
シリーズが多い分類で、どれがどのシリーズか見分けるためのものです。

```
因幡電工｜配管化粧カバー（一般用）
  LD-70  スリムダクトＬＤ   ← 青
  MD-751 スリムダクトＭＤ   ← 緑
  SD-66  スリムダクトＳＤ   ← 橙
```

使える色は **青 / 緑 / 橙 / 赤 / 紫 / 茶 / 水 / 桃 / 灰 / 黒** です。
`#1565c0` のような色コードでも指定できます。
決めた名前と色コード以外は無視されるので、知らないCSVを取り込んでも
おかしな見た目にはなりません。

色は**画面だけ**のものです。見積書や請求書の印刷には出ません。

因幡電工の配管化粧カバー（一般用）では、**カバーの幅**で色を分けています。
同じシリーズでも幅が違うと部材が合わないので、取り違えを防ぐためです。

| 幅 | 色 | シリーズ | 件数 |
|---|---|---|---|
| 66 | 水 | SD | 18 |
| 70 | **青** | LD | 23 |
| 75 | 緑 | MD | 17 |
| 77 | 橙 | SD | 39 |
| 85 | 茶 | MD | 17 |
| 90 | **赤** | LD | 23 |
| 100 | 紫 | SD | 23 |
| 140 | 桃 | SD | 14 |

幅はシリーズをまたいで重複していないので、**色を見ればシリーズも分かります**。
規格欄にも「幅70」と文字で入るので、色が見分けにくいときはそちらで確認できます。

幅は品番から読み取っています（`LD-70` → 70、`MD-751` → 75）。
読み取れないものは色を付けません（配管固定サドル `SL-300` は幅の概念が無いため）。

### 並びも幅ごとにまとまっています

その現場で使う幅の部材を続けて拾えるよう、**幅ごとにまとめて並べて**あります。

```
幅70（LD） 23件 → 幅90（LD） 23件
  → 幅75（MD） 17件 → 幅85（MD） 17件
    → 幅66（SD） 18件 → 幅77（SD） 39件 → 幅100（SD） 23件 → 幅140（SD） 14件
      → 幅なし（配管固定サドル） 1件
```

シリーズは **LD → MD → SD**、その中は幅の細い順です。
各幅の中は、ダクト本体 → ウォールコーナー → コーナー → ジョイント …と、
因幡電工のサイトに載っている部材の順を保っています。

### ビル設備用も同じしくみです

| 幅 | 色 | シリーズ | 件数 |
|---|---|---|---|
| 90 | 水 | PD | 23 |
| 120 | 青 | PD | 24 |
| 140 | 緑 | PD | 11 |
| 150 | 橙 | RD | 37 |
| 300 | 茶 | RD | 197 |
| 450 | 赤 | RD | 204 |
| 600 | 紫 | RD | 202 |
| 900 | 桃 | RD | 215 |
| — | 色なし | サイズを持たない金具・ジョイント類 | 32 |

並びは **PD（細い順）→ RD（細い順）**です。

**色は分類ごとに独立しています。** 一般用の「幅90＝赤」と
ビル設備用の「幅90＝水」は別物ですが、同時に見ることは無いので混乱しません。

ビル設備用は**材質も規格に出しています**。同じ形・同じ幅でも価格が大きく違うためです。

```
RD-150-A-ZA    幅150 ZA  1本2m（1本入）   ¥20,000
RD-150-A-SUS   幅150 SUS 1本2m（1本入）   ¥55,900   ← 約2.8倍
```

### 変えたいとき

`scrape.mjs` の `WIDTH_SCHEME` に分類ごとの設定がまとまっています。

```js
const WIDTH_SCHEME = {
  '配管化粧カバー（一般用）': {
    widths: [66, 70, 75, 77, 85, 90, 100, 140],   // 幅とみなす数字
    color:  { 66:'水', 70:'青', 75:'緑', 77:'橙',
              85:'茶', 90:'赤', 100:'紫', 140:'桃' },
    order:  [70, 90,  75, 85,  66, 77, 100, 140], // 並べる順
  },
  '配管化粧カバー（ビル設備用）': { … },
};
```

ここに分類を足せば、他の分類（ドレン管など）にも同じしくみを広げられます。
