================================================================
　空調王｜元締めの道具　2026-09-12
================================================================

ここは BIGBOSS の手元だけで動かす道具です。サイトには出ません。

やることは2つだけ。
　・空調王の本体をクラウドに載せる（版を上げるたび）
　・ライセンスキーを配る／期限を延ばす／止める


----------------------------------------------------------------
■ 最初の1回だけ（10分）
----------------------------------------------------------------

【1】クラウドに書き込むための鍵をもらう

　1. https://console.firebase.google.com/ を開く
　2. プロジェクト「airtec-sync」を選ぶ
　3. 左上の歯車 →「プロジェクトの設定」
　4. 上のタブ「サービス アカウント」
　5. 下のほうの「新しい秘密鍵の生成」→「キーを生成」
　6. JSONファイルが落ちてくる
　7. そのファイルを、このフォルダに
　　　　service-account.json
　　という名前で置く（名前を変えてください）

　★ この JSON は、パスワードそのものです。
　　 人に見せない。メールで送らない。GitHubに上げない（.gitignore済み）。
　　 アスラーダも中身は見ません。


【2】クラウドの許可設定を貼り直す　★これを忘れると誰も開けません

　1. https://console.firebase.google.com/ → airtec-sync
　2. 左メニュー「Firestore Database」→ 上のタブ「ルール」
　3. いま出ている文字を全部消して、
　　　　asurada\tools\estimate\firestore.rules
　　の中身を丸ごと貼り付ける
　4. 「公開」を押す

　前と違うのは1行だけです（読める置き場所に lic と app を足しました）。
　貼っていないと、空調王の画面に
　　　「空調王の設定に直しが要ります。」
　と出ます。そう出たら、ここを忘れています。


----------------------------------------------------------------
■ ふだんは、この1行だけ覚えていれば足ります
----------------------------------------------------------------

　黒い画面（ターミナル）で

　　cd C:\Users\toooo\OneDrive\デスクトップ\asurada\_kuchoo-admin
　　node admin.mjs serve

　と打つと、こう出ます。

　　http://127.0.0.1:8790/?t=（毎回ちがう長い文字）

　その住所をブラウザに貼ると、元締めの画面がひらきます。
　あとは全部ボタンです。

　　［本体を載せる］　　空調王を直したあと、みんなに届ける
　　［＋ キーを発行する］会社名と期限を入れるとキーが出る。コピーして渡すだけ
　　［のばす］　　　　　入金を確認したら期限を延ばす
　　［止める］　　　　　解約されたとき
　　［確かめる］　　　　その人が本当に開けるか、お客さんと同じ順番でたどる
　　［見直す］　　　　　いまの調子をもう一度見る

　終わるときは、黒い画面で Ctrl + C。

　★ 画面のいちばん上に「調子」が出ます。**困ったらまずここを見てください。**
　　 とくに「クラウドの許可設定」は、お客さんとまったく同じやり方で
　　 確かめているので、ここが ○ なら本当に開けます。

　★ サービスアカウントの鍵は、ブラウザには渡していません。
　　 鍵は黒い画面の中（node）だけにあり、画面は頼みごとをするだけです。
　　 だから、この住所は自分のパソコンの外からは開けません。


----------------------------------------------------------------
■ 空調王を直したあと、みんなに届けるまで
----------------------------------------------------------------

　1) cd asurada\tools\estimate
　   node build.mjs                  ← 本体を1本に固める
　2) 元締めの画面で ［本体を載せる］  ← クラウドに載せる
　3) git push                        ← 入口（index.html）を配る

　※ 版番号は version.txt を書き換えるだけでよくなりました。
　　 build.mjs が index.html と app.js を機械的にそろえます。

　※ 2) を忘れると、お客さんには古いままが届きます。
　　 「調子」の画面が〈手元の本体〉と〈載せてある版〉を並べて出すので、
　　 ずれていたらそこで気づけます。


----------------------------------------------------------------
■ 黒い画面から直に打ちたいとき
----------------------------------------------------------------

　node admin.mjs doctor                      いまの調子（★困ったらまずこれ）
　node admin.mjs list                        いま誰に配っているか
　node admin.mjs issue "今野空調" 2027-03-31  キーを1つ発行する
　node admin.mjs renew  今野空調 2028-03-31   期限を延ばす
　node admin.mjs revoke 今野空調              止める
　node admin.mjs publish                     本体をクラウドに載せる
　node admin.mjs publish --rotate            合鍵を作り直す
　node admin.mjs check  <キー>                その人が開けるか確かめる

　止めたとき、相手の端末は手元の控えが切れたところ（最長30日）で開かなくなります。
　すぐ止めたいときは［合鍵を作り直す］。契約中の人の札は自動で書き直されます。


----------------------------------------------------------------
■ いちばん大事な順番
----------------------------------------------------------------

　鍵を入れた日に、自分が閉め出されないように。

　　① Firebase のルールを貼り直す（上の【2】）
　　② cd tools\estimate && node build.mjs
　　③ 元締めの画面で ［本体を載せる］
　　④ ［＋ キーを発行する］で「50Airtec」　　← **自分のぶんが先**
　　⑤ ［＋ キーを発行する］で「今野空調」　　← いま使っている人
　　⑥ ［確かめる］を押して、両方とも ○ が並ぶのを見る
　　⑦ 自分と今野空調さんの端末で、実際にキーを入れて開く
　　⑧ そこまで済んでから git push

　★ ⑥⑦を飛ばさないでください。
　★ ①を忘れると、⑦で誰も開けません（画面に「設定に直しが要ります」と出ます）。


----------------------------------------------------------------
■ licences.json を消さないこと
----------------------------------------------------------------

　誰にどのキーを渡したかは、このフォルダの licences.json に控えます。
　クラウドの札は**そのキーで暗号にしてある**ので、
　キーを無くすと、こちらからも読めなくなります。

　パソコンを替えるときは、このファイルも一緒に持っていってください。
　（.gitignore に入れてあるので、GitHubには上がりません）
